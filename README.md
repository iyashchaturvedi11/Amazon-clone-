# Basic Amazon Clone

This project is a **Basic Amazon Clone** built using only HTML and CSS. It is a simple static web page that mimics the look and feel of Amazon’s homepage and product listing pages to demonstrate frontend design and layout skills.

## Demo

You can open the `index.html` file in any modern web browser to view the project locally.

## Features

- Clean and responsive layout inspired by Amazon's design
- Header with logo, search bar, and navigation links
- Product grid layout to showcase items
- Product cards with images, titles, prices, and ratings
- Footer section with useful links

## Technologies Used

- HTML5
- CSS3 (Flexbox and Grid for layout)
- Responsive design principles
